--------------------------------------------------------------------------------
1. PROJECT OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
- Application Name: Haedo Futsal App (haedo-futsal-app)
- Repository Name: WillyBit78/WebApp-HF
- Application Type: Progressive Web App (PWA) for Comprehensive Sports Club Management.
- Primary Objective: Manage club membership roster (Socios), monthly fee collection and payment verification via OCR transfer receipts or cash, strict monthly fee periods (YYYY-MM), institutional notices with web push notifications & foreground popups, match & event calendar, role-based user management (Admin, Adm.Club/Contador, Coach, Staff, Member/Socio), cash vs bank balance tracking by staff member, and official club store.

--------------------------------------------------------------------------------
2. CONNECTED PLATFORMS & INTEGRATION (.env LOCATION)
--------------------------------------------------------------------------------
The project is integrated with three core services:
1. GitHub: Core code repository (WillyBit78/WebApp-HF).
2. Supabase: Backend-as-a-Service (PostgreSQL Database, Auth, Storage for face photos and payment receipts).
3. Vercel: Continuous Deployment hosting linked to the GitHub repository for automatic builds on push.

CRITICAL: ALL CREDENTIALS, API KEYS, AND TOKENS ARE STORED IN THE ENVIRONMENT FILE .env LOCATED AT THE PROJECT ROOT (Z:\Willy\Proyectos\App Club\Nueva APP\.env).

Keys stored in .env include:
- Supabase URL & Public/Service Keys
- PostgreSQL Connection String / Supabase Pooler
- Mercado Pago Access Token
- VAPID Keys for Web Push Notifications
- Google Gemini API Key (for receipt OCR processing)

4. TECH STACK & ARCHITECTURE
--------------------------------------------------------------------------------
- Frontend Framework: React 18 + Vite + Tailwind CSS 3 + Lucide React + clsx + tailwind-merge.
- Backend & DB: Supabase (@supabase/supabase-js) + PostgreSQL (pg).
- PWA & Service Worker: Web Share Target (sw.js), Web Push Notifications (web-push), Web App Manifest.
- Payment Receipt OCR: @google/generative-ai (Gemini Flash 1.5/2.0) + pdfjs-dist (PDF to canvas rendering).
- Layout & Navigation: Responsive, role-based (App.jsx, desktop Sidebar.jsx, mobile BottomNav.jsx, top Navbar.jsx).

5. FEATURE BREAKDOWN & HISTORICAL CONFIGURATIONS
--------------------------------------------------------------------------------

A. ROLE-BASED NAVIGATION & INITIAL VIEW (App.jsx, BottomNav.jsx, Sidebar.jsx, Navbar.jsx)
   - Initial View: ALL Staff roles (Admin, Adm.Club/Contador, Coach, Staff) land directly on Panel Principal (currentTab = 'dashboard') upon login, clicking the "Inicio" tab, or clicking the Club Shield Logo (/logo.png).
   - Socio (Member): Home/Dashboard (DashboardSocio), Calendar, Notices, Store.
   - Staff: Panel Principal (MainDashboardSummary), Calendar, Notices, Store, Member Roster (Gestión de Socios).
   - Coach: Panel Principal (MainDashboardSummary), Calendar, Notices, Store, Member Roster (Gestión de Socios), Cash Fee Collection.
   - Adm.Club / Contador (Accountant): Panel Principal (MainDashboardSummary), Member Roster, Financial Control (Income/Expenses/Audit), Calendar, Notices, Store.
   - Admin: Full system access (Panel Principal, Socios, Calendar, Notices, Store, Financials, System/Staff Config).

B. PANEL PRINCIPAL (MAIN DASHBOARD SUMMARY - MainDashboardSummary.jsx)
   - Structured Card Order:
     1° ESTADO DE CUOTAS MENSUAL: Large 3D Donut Chart, % AL DÍA centered badge, and fee breakdown (Al Día, En Revisión, Pendientes, Total Padrón). Direct navigation to Gestión de Socios (users).
     2° COMUNICADOS DEL CLUB: Summary of active notices, notice count, and latest official announcement title. Direct navigation to Comunicados (notices).
     3° SECTOR FINANZAS (Staff Admin/Contador): Net monthly balance, income vs expenses breakdown. Direct navigation to Finanzas (finance). Clickable balance cards open Cash vs Bank breakdown.
     4° AUDITORÍA DE PAGOS (Staff Admin/Contador): Pending receipt audit count. Direct navigation to Auditoría (finance with en_revision filter).
   - Includes compact HistorialMovimientosTable right below summary cards for immediate financial visibility.

C. MEMBER ROSTER & FEE PERIOD REGULATION (DashboardSocios.jsx, ModalAddUser.jsx, ModalFichaSocio.jsx, AppContext.jsx)
   - Strict Monthly Fee Rule: On the last day of each month, the new month's fee becomes available. Unpaid accounts transition to PENDIENTE.
   - No Automatic Day 20-31 Rollover: Payments on days 20-31 of a month count strictly for that month unless already paid. August 2026 starts at 0% AL DÍA (100% Pendiente) until explicit 2026-08 payments are made.
   - Period Selectors (YYYY-MM): Provided in PaymentUploader.jsx and DashboardSocios.jsx cash modal so users/staff can select which month is being paid.
   - Profile History Breakdown (ModalFichaSocio.jsx): Renders a 4-month status grid (Agosto, Julio, Junio, Mayo) with AL DÍA / PENDIENTE badges and full receipt operation details.
   - Toolbar & Buttons: Action buttons aligned in a single row (+ Socio | Link | + Staff) with reduced mobile padding.
   - Coach Badges: Display assigned Coach/DT badges at both Discipline and Category header levels.

D. FINANCIAL CONTROL, COMPACT MOVEMENTS TABLE & STAFF CASH BREAKDOWN (DashboardContador.jsx, HistorialMovimientosTable.jsx, ModalDetalleCajaEfectivo.jsx)
   - Sub-Tabs Grid: Top 4 finance action buttons arranged in a 2x2 grid (Line 1: Balance | Transf. MP, Line 2: Comprobantes | $ Cuotas).
   - Mercado Pago Feed: Header title simplified to "Transferencias Recibidas". Filter buttons arranged in a 2x2 grid (Sin Conciliar, Conciliadas, Descartadas, Todas).
   - Compact Movements Table (HistorialMovimientosTable.jsx):
     * FECHA: Formatted as short DD/MM/AA.
     * CAJA: Display initial badge C (Cuotas) or T (Torneos).
     * TIPO: Hidden (implied by +/- sign and green/red color of Monto).
     * MONTO: +$50.000 (green) / -$10.000 (rose).
     * CONCEPTO: Description text.
     * STAFF: Header "Staff", displaying ONLY the first name of the member (e.g. Willy, Bocha).
   - Cash vs Bank Breakdown (ModalDetalleCajaEfectivo.jsx): Clicking any balance total card (Balance General, Caja 1 Cuotas, Caja 2 Torneos) opens popover showing En Cuenta MP vs En Efectivo. Clicking En Efectivo expands per-staff physical cash in hand (collected income minus expenses).

E. INSTITUTIONAL NOTICES & PUSH NOTIFICATIONS IN FOREGROUND (NoticeBoard.jsx, sw.js, api/send-push.js)
   - Push Deep Linking: Push notifications include noticeId in URL (/?tab=notices#notices:${noticeId}). Clicking notification opens app directly on Avisos tab.
   - Foreground Notice Modal (Primer Plano): Opened notice displays in a high-impact modal popup with title, message, emisor name, urgency badges, and an explicit "✓ ¡Entendido! Marcar como Leído" button that marks ONLY that notice as read.
   - No Automatic Mark-All-Read: Removed automatic mark-all-read on mount so unread notices retain their status until viewed.

F. OCR RECEIPT READER & WEB SHARE TARGET (PaymentUploader.jsx, sw.js)
   - Parsing Loading Screen: Uses official club logo (/logo.png), soft red backdrop glow, and spinning blue ring matching app startup screen.
   - Cash Payment Collection: Coaches and Admins can record cash fee payments directly from socio profile modal or dashboard.

G. OFFICIAL CLUB STORE & FOOTER
   - Store accessible via BottomNav.jsx (mobile) and Sidebar.jsx (desktop).
   - Standardized Footer: "© 2026 Haedo Futsal App - Sistema de Gestión Integral".

6. SUPABASE DATABASE SCHEMA (users & CORE TABLES)
--------------------------------------------------------------------------------
users Table:
- id: Text format usr-[DNI] or generated text
- dni: Document text
- nombre: Full Name / Staff Name
- apellido: SURNAME in UPPERCASE (or empty for Staff)
- telefono: WhatsApp phone string
- fecha_nacimiento: Birthdate text
- hincha_de: Club preference text
- nombre_contacto: Tutor/Family contact name
- telefono_contacto: Tutor WhatsApp phone
- foto_rostro: Official face image URL/base64
- clave: 4-digit PIN (default 1234)
- rol: socio, staff, coach, contador (Adm.Club), admin
- categoria: Assigned sports category, or joined Coach categories string (e.g. "BAFI Femenino, EDEFI Baby")

payments Table (camelCase columns):
- id, socioId, socioNombre, numeroOperacion, monto, billeteraOrigen, emisorNombre, fechaTransferencia, comprobanteUrl, estado, observaciones, created_at.

Core Tables:
- notices: Institutional announcements and news.
- events: Matches, training sessions, and calendar events.
- movimientos: Cash/bank income and expenses.
- push_subscriptions: Device push notification tokens.
